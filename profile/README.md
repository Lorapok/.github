## Core Philosophy

**Biological UI** — Interfaces with pulse. Visual systems use depth, signal, and organic rhythm so software feels responsive instead of static.

**Sensory Computing** — Fast feedback loops. Products prioritize latency, clarity, and direct interaction so users can feel what the system is doing.

**Open Engineering** — Readable by default. Projects ship with practical docs, public repos, and simple paths for people to learn, fork, and extend.

## Featured Product Line

### Developer Tools

**Lorapok API Atlas** `TypeScript`
- Polished atlas for discovering public APIs and open data sources
- [Live](https://lorapok.github.io/) · [Repo](https://github.com/lorapok/api-atlas)

**Lorapok LocalSync** `JavaScript`
- Privacy-focused communication over local router network without external servers
- [Live](https://lorapok.github.io/) · [Repo](https://github.com/lorapok/localsync)

**Laravel Execution Monitor** `PHP`
- Zero-config Laravel performance monitor for tracking runtime behavior
- [Live](https://lorapok.github.io/) · [Repo](https://github.com/lorapok/laravel-execution-monitor)

### AI

**Lorapok AI Agent** `JavaScript`
- Terminal-first AI coding agent that plans, executes, verifies, and deploys
- [Repo](https://github.com/lorapok/ai-agent)

**Dynamic Ollama LLM Chat** `Python`
- Complete setup for running local models with Ollama, API access, VS Code workflows, and dynamic console UI
- [Live](https://lorapok.github.io/) · [Repo](https://github.com/lorapok/dynamic-ollama-chat)

### Media

**Lorapok Media Player** `TypeScript`
- Desktop-grade media player built for low-latency playback, high-fidelity control, and sensory UI aesthetics
- [Live](https://lorapok.github.io/) · [Repo](https://github.com/lorapok/media-player)

### Language / Input

**Lorapok Keyboard** `Kotlin`
- Android Bengali keyboard with phonetic typing, context-aware prediction, and large vocabulary engine
- [Live](https://lorapok.github.io/) · [Repo](https://github.com/lorapok/keyboard)

## Onboarding Protocol

**Developer** → Clone API Atlas or AI Agent. Explore the codebase.

**Designer** → Study Media Player's biological UI patterns.

**Privacy Advocate** → Deploy LocalSync on your local network.

**Laravel Dev** → Install Execution Monitor via Composer.

**Bengali Speaker** → Try Lorapok Keyboard on Android.

**AI Researcher** → Run Dynamic Ollama Chat with your local models.

## Contribution Matrix

```bash
# 1. Fork the repository
# 2. Initialize local environment
git clone https://github.com/YOUR_USERNAME/lorapok-repo.git
cd lorapok-repo

# 3. Create feature branch
git checkout -b feature/amazing-feature

# 4. Commit changes
git commit -m "feat: add amazing feature"
```
