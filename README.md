## 🤝 How to Contribute

We believe the best software is built together. Whether you're fixing a typo or architecting a new feature, you're welcome here.

```bash
# 1. Fork the repository
# 2. Clone your fork
git clone https://github.com/YOUR_USERNAME/lorapok-repo.git

# 3. Create your feature branch
git checkout -b feature/amazing-feature

# 4. Make your changes and commit
git commit -m "feat: add amazing feature"

# 5. Push and open a Pull Request
git push origin feature/amazing-feature
```

> 💡 **New to open source?** Check out our [Good First Issues](https://github.com/search?q=org%3Alorapok+label%3A%22good+first+issue%22&type=issues) to get started!
